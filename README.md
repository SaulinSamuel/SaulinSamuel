### 📌 Projeto em destaque

#### [API Academia](https://github.com/SaulinSamuel)
Sistema completo de gestão de academias, com foco em arquitetura sólida e práticas de mercado:

- Autenticação e autorização **stateless com JWT** e `@PreAuthorize` por papéis (roles)
- Arquitetura orientada a eventos (`ApplicationEventPublisher` + `@TransactionalEventListener`)
- Regras de negócio para mensalidades, agendamentos, aulas e histórico de acesso
- Jobs agendados (`@Scheduled`) para cancelamento e conclusão automática de aulas
- **Rate limiting** com Bucket4j
- Migrações de banco versionadas com **Flyway**
- Suíte com mais de **170 testes** (unitários, slice e integração com Testcontainers)
- **CI/CD completo**: build e testes automatizados, imagem Docker publicada no GHCR e deploy contínuo no Render

#### Mercadinho
Sistema de gestão de mercado (mini-ERP), também construído em Spring Boot:

- API REST completa com autenticação **JWT**
- CRUD de produtos, estoque e vendas
- Frontend próprio em HTML/JS (SPA) consumindo a API
- Projeto que consolidou minha base em arquitetura de APIs antes do API Academia
